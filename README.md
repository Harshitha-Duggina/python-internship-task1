#### FILE AUTOMATION SCRIPT
## Overview
This project is a simple File Automation Script built using Python.It allows users to perform basic file and folder operations automatically using a menu.
It uses a menu system where the user can choose different operations.

## Objective
The main goal of this project is to:
 - Learn Python file handling
 - Understand automation basics
 - Practice error handling and logging
   
## Features
* Create new directories
* View files inside a folder
* Create and write content to a file
* Read content from a file
* Automatic logging of all actions

 ## Technologies used
 * Python
 * os(for file & directory operations)
 * logging(for tracking actions and errors)

 ## How to run the program
 1. Save the file as import os.py
 2. Open Terminal
 3. Go to python folder
 4. Run the code

## Program Menu
When you run the program,you will see
`````````````````````````````````````
--- Automation Menu ---         
1.Create Directory
2.List Files
3.Write  to File
4.Read File
5.Exit
`````````````````````````````````````
Enter the number to perform the required operation.

## Error Handling
*Handles invalid inputs
*Shows error inputs
  -Wrong file name
  -Invalid directory path
  -File not found
*All errors are saved in log file
